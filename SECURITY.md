# Security Policy

## Supported versions

Security fixes are evaluated for the latest public release of BladeCP for
WHMCS. Pre-release versions, including release candidates, may be updated or
superseded as part of the normal release process.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by email:

<dev@bladecp.com>

Include enough information for us to reproduce and assess the issue, such as:

- A clear description of the impact.
- Affected module version and WHMCS/PHP versions.
- Reproduction steps or a minimal proof of concept.
- Any relevant logs, with API keys, passwords, customer information, and other
  sensitive data removed.

Do not open a public GitHub issue, publish exploit details, or share a proof of
concept that could expose users while the issue is being assessed.

## What happens next

We will acknowledge the report, assess its impact, and coordinate an
appropriate fix and disclosure. We do not publish a fixed response-time
commitment. Please allow time for investigation and, where needed, for users
to apply a release safely.

## Scope

This policy covers the BladeCP for WHMCS module distributed from
[`bladecp/bladecp-whmcs`](https://github.com/bladecp/bladecp-whmcs). For issues
in third-party software, including WHMCS itself, please contact the relevant
vendor as well.
